# Login design preview

A standalone React JS login prototype for Simplified Management. It contains original copy and no live authentication or existing website assets.

Run `npm install`, then `npm run dev`. Open http://127.0.0.1:4180.

Run `npm run build` for a production build. To serve an existing build without extra dependencies, run `node preview.mjs`.

The sign-in and recovery forms are demonstrations only; they do not transmit credentials or send emails. Wire them to the application's authentication service when integrating the approved design.
